Lịch sử phiên bản

Mỗi bản phát hành được build tự động và ký bằng keystore của nhà phát triển.

v1.0.0 — Bản đầu tiên

Chưa phát hành
  • Camera Studio: chụp ảnh, quay video, zoom, focus, torch, hẹn giờ, lưới bố cục.
  • AI Vision offline: face detection, landmark, tư thế đầu, điểm chất lượng ảnh.
  • Photo Studio: 7 công cụ chỉnh sửa, 7 bộ lọc, undo/redo, so sánh trước–sau.
  • Video Studio: trim, xoay, lật, tắt tiếng, nén 720p, trích frame.
  • Media Library: tìm kiếm, lọc, chọn hàng loạt, import SAF.
  • Processing Center: hàng đợi WorkManager với pause/resume/cancel/retry.
  • Device Center & Security Center: thông tin phần cứng, Keystore, PIN, sinh trắc học.
  • Dashboard đọc số liệu thật từ Room database.
Trạng thái hiện tại: chưa phát hành. Khi repository được gắn tag v1.0.0, GitHub Actions sẽ build, ký, tính SHA-256 và công bố file APK tại đây.

Quy trình phát hành

Tất cả tự động, không cần VPS.

Gắn tag phiên bản

git tag v1.0.0 && git push origin v1.0.0

CI build & ký APK

Workflow android-release.yml chạy lint, unit test, build release, ký bằng secrets.

Công bố GitHub Release

APK và file SHA-256 được đính kèm vào release công khai.

Cập nhật website

CI ghi lại website/data/release.json để trang tải hiển thị đúng phiên bản, dung lượng và SHA-256.
