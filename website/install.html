Cài đặt

Cài APK trong 5 bước

APK được phân phối ngoài Google Play nên bạn cần bật cài đặt từ nguồn không xác định.

Tải file APK

Mở trang tải trên chính điện thoại Android và tải vcam-pro-ultimate.apk.

Kiểm tra SHA-256 (khuyến nghị)

So sánh mã SHA-256 trên trang tải với mã tính từ file. Nếu khác nhau, xoá file và tải lại.

Cho phép cài từ nguồn không xác định

Cài đặt → Ứng dụng → Trình quản lý file/Chrome → Cài đặt không xác định → Bật.

Mở file và cài đặt

Mở file trong thư mục Downloads, chọn Cài đặt. Nếu có cảnh báo Play Protect, chọn “Vẫn cài đặt”.

Cấp quyền cần thiết

Camera và micro (để quay video có tiếng). Ứng dụng không yêu cầu quyền Internet.

Cài đặt qua ADB (dành cho kiểm thử)

adb install -r vcam-pro-ultimate.apk
adb shell pm list packages | grep vcampro

Gỡ bản debug trước khi cài bản release nếu package name khác nhau (com.vcampro.ultimate.debug so với com.vcampro.ultimate).

Kiểm chứng chế độ offline

Sau khi cài, bật Airplane Mode rồi lần lượt mở Camera, chụp ảnh, quay video, tạo hồ sơ, phân tích AI, chỉnh ảnh, xuất video và mở lại thư viện. Tất cả phải hoạt động bình thường — ứng dụng không có quyền INTERNET nên không thể phụ thuộc máy chủ.
